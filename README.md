# Projet.DeveloppeurPython.Manel.Ocana.2026
Développeur Python



Ce dépôt regroupe trois projets réalisés dans le cadre de la formation Développeur Python-fullstack.

L’objectif est de progresser à travers trois niveaux de développement web :
- Frontend statique
- Backend sans framework
- Application fullstack avec framework

---

## 📁 Structure du projet

block-1-frontend/
block-2-backend/
block-3-framework/



Chaque bloc correspond à une étape de la formation.

---

## 🧩 Block 1 - Frontend statique

Projet réalisé en HTML et CSS.

Objectifs :
- Structurer une interface web
- Travailler le design et l’ergonomie
- Comprendre les bases du développement frontend

---

## 🧩 Block 2 - Backend from scratch

Backend développé en Python sans framework.

Objectifs :
- Comprendre la logique serveur
- Manipuler les données côté backend
- Construire une architecture simple sans dépendances externes

---

## 🧩 Block 3 - Framework (Flask + Jinja2 + MySQL)

Application web complète avec Flask.

Technologies :
- Python
- Flask
- Jinja2
- MySQL

Objectifs :
- Développement d’une application fullstack
- Gestion des templates dynamiques
- Connexion à une base de données relationnelle
- Architecture web structurée

---

## 📚 Documentation

Chaque projet contient un dossier `docs/` incluant :

- 📸 Captures d’écran du projet
- 📄 Présentation PDF expliquant le projet

Ces éléments permettent de comprendre rapidement le projet sans exécuter le code.

---

## 🚀 Objectif du dépôt

Centraliser les projets de formation et illustrer la progression technique à travers trois niveaux de développement.
